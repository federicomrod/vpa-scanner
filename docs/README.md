# docs/

Design documents for this project. Two files belong here and are treated
as the authoritative source of truth for everything the code does:

- `concept-v2.md` - the frozen signal specification (what a "candidate"
  is and how it is detected). Implemented in `src/vpa/signal/`.
- `architecture-v2.md` - the infrastructure and change-control design
  (how the system is put together, and how changes to it are reviewed).

These are added and updated by the project owner, not generated by code.
If anything in the code seems to contradict one of these documents, the
document wins - stop and ask rather than guessing which is right.
